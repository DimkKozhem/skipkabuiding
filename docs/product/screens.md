# Экраны

Интерфейс — рабочее место инспектора. Каждый экран отвечает на один вопрос. Если блок не помогает ответить — его нет в главном UI.

Приложение: `http://127.0.0.1:8000` после `sitewatch ui`.

## Старт

| Экран | Вопрос инспектора |
|-------|-------------------|
| Объекты | Какие объекты на площадке и где уже есть сигнал? |
| Добавить объект | Как завести новый объект? |
| О проекте | Что это за площадка? |

Витрина объектов показывает обложку с последним реальным кадром. Нет кадра — пустое место и действие «добавить фото» или «подключить источник». Без выдуманных стоковых картинок.

## Внутри объекта

| Раздел | Вопрос инспектора |
|--------|-------------------|
| Обзор | Что сейчас с этим объектом? |
| Камеры / источники | Откуда приходят кадры? |
| План-факт | Что ожидалось и что наблюдается? |
| Хронология | Как менялась картина во времени? |
| Сигналы | Что система просит проверить по этому объекту? |
| Заметки | Что инспектор уже зафиксировал словами? |
| Настройки | Как устроен объект и его источники? |

## Глобальная очередь сигналов

Экран `/signals` — список ситуаций, которые требуют внимания по площадке. Это не «dashboard алертов», а очередь работы инспектора:

1. открыть сигнал;
2. посмотреть план и факт;
3. посмотреть кадры;
4. прочитать «что проверить»;
5. принять решение с причиной.

## Как говорить на экранах

Можно: «признаки», «возможное отклонение», «требуется проверка», «нет наблюдаемой динамики».

Нельзя: «стройка остановлена», «нарушение доказано», «система подтвердила».

Технические коды (`zone_a`, `site_001`, UUID наблюдений) не являются заголовками для человека. В интерфейсе — человеческие имена объектов и понятные формулировки.
