# Блок-схема решения

Как устроена Скрипка — коротко, для слайда.

## Цепочка

```text
График объекта          Камера / фото / видео
        \                       /
         \                     /
          →  Наблюдаемый факт  ←
                    ↓
              План и факт
           (сравнение)
                    ↓
                 Сигнал
        (кадры · что проверить)
                    ↓
          Решение инспектора
     подтвердить / отклонить /
        нужно больше данных
```

## По шагам

1. **График объекта** — что должно быть к этой дате.
2. **Камера / фото / видео** — что видно на площадке.
3. **Наблюдаемый факт** — техника, этажность, изменение во времени.
4. **План и факт** — сверка ожидания и наблюдения.
5. **Сигнал** — возможное отклонение, кадры, «что проверить».
6. **Решение инспектора** — подтвердить, отклонить или запросить ещё данные.

## Одна фраза под схему

Автоматика ведёт до сигнала. Вердикт о положении дел — только человек.
