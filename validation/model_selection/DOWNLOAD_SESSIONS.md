# Загрузки весов: сессия не должна умирать вместе с командой агента

Причина обрыва MolmoPoint-8B (2026-09-27): **время жизни фоновой команды Cursor**. В логах нет Python traceback и нет нехватки диска. `status: aborted`, `exit_code: unknown`. Повтор через ~40 с оборвался так же. Последующий `huggingface_hub snapshot_download` ещё и зависал на CDN без роста `.incomplete`. Докачка прошла через `curl -C -` в `setsid`/`nohup`.

## Правило для всех агентов

1. Не считать загрузку идущей, пока она жива только как shell-задача инструмента. Процесс должен пережить завершение команды: `setsid` + `nohup`, свой PID-файл и лог в `artifacts/model_compare/`.
2. Один загрузчик на один checkpoint. Перед стартом проверить PID и имя процесса. Чужой живой загрузчик не убивать и не дублировать.
3. Файл исправен только если размер совпал с индексом той же revision. Наличие файла и суффикс `.incomplete` не считаются готовностью. Незаконченное не переименовывать в готовое.
4. Продолжать с места обрыва (`curl -C -` или клиент, который умеет Range). Целые части не скачивать заново.
5. Если та же ошибка повторяется без прироста байтов — остановить одинаковые попытки и записать blocker. Не запускать третий такой же `snapshot_download` в фоне инструмента.
6. Прокси, которым докачка Molmo реально пошла: `http://127.0.0.1:10808`.

Эталонные скрипты: `artifacts/model_compare/molmo_curl_resume.sh`, `artifacts/model_compare/internvl_curl_resume.sh`.
