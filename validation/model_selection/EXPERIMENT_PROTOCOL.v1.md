# Протокол отбора

Зафиксирован до оценки кандидатов этого цикла. Промпты не менялись. Verification set не открывался.

## Задачи

Отдельные решения, без универсального победителя:

1. Этажность видимых надземных уровней целевого корпуса.
2. Окна и проёмы. Окно не равно проёму. Сравнение с этажами не смешивается.
3. Видимые признаки работ: фасад, кровля, котлован, фундамент, разделитель. Признак не означает завершение. Метры без калибровки не измеряются.
4. Техника как ресурс, не как выполнение работы.
5. Динамика: появление, изменение, отсутствие видимых изменений, несопоставимость кадров. Разрыв в днях не является непрерывным видео.
6. Режим: локальный или удалённый.

Perception не получает плановые количества и сроки. `unknown` не становится 0. Пустая видимая зона может подтверждать отсутствие объекта. Пустой ответ модели — нет. Ранний котлован не обязан давать число этажей. Повтор одной ошибки не подтверждение. Согласие моделей не эталон.

## Пороги до прогона

- Этажи: exact match и MAE только на кадрах с human GT и `counts_toward_accuracy=true`. Сейчас таких кадров 0. Отказ на `visibility=none` и число на пригодном кадре считаются отдельно. Покрытие — доля пригодных кадров с ответом, не с отказом.
- Локализация: бокс считается совпадением при IoU ≥ 0.3. Точка — если после перевода crop→original она ближе 32 пикселей к точке GT. Линия этажа — если средняя абсолютная ошибка y на кропе ≤ 8% высоты кропа и линия не попадает в полосу кровли/проезда, размеченную отдельно.
- Работы: TP/FP/FN по наблюдаемым признакам. Ложное «завершено» по одному признаку дисквалифицирует использование ответа как факта завершения, даже если признак верный.
- Динамика: четыре класса — появилось, изменилось, видимых изменений нет, кадры несопоставимы. Ошибка ракурса, света и снега пишется отдельно.
- Gate отбора: ложных подтверждений меньше при покрытии ≥ 0.5 пригодных кадров, затем больше верных фактов, затем локализация, затем цена и задержка. Сплошной отказ не победа. На малом n публикуются абсолютные количества. Неопределённость — по эпизодам, не по соседним кадрам как по независимым.
- Ошибки API, parse, truncation и пустой ответ — эксплуатационная доступность, отдельно от качества ответа.
