## Жёсткие ограничения

1. Автоматическое подтверждение **типа** машины — выкл.
2. `missing_equipment` по этим детекторам — выкл.
3. В операционный факт тип попадает только после решения инспектора.
4. Class-agnostic сигнал = «признаки техники / требуется проверка», не «это excavator».
5. **40,9%** верного типа у YOLOE — доля среди геометрически совпавших рамок, не точность всей системы. Пропуски и лишние рамки в эту долю не входят.

## План пилота (не менять без новой задачи)

1. Показывать рамку «предположительно техника».
2. Тип сохранять как предложение модели.
3. Подтверждённый тип — только после решения инспектора.
4. Автоматический `missing_equipment` по новым детекторам оставить выключенным.
